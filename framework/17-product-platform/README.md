# Product Platform

Product Platform is a parent family for related UEEF framework packs.

## Child packs

- [`01-identity-access-application-models`](01-identity-access-application-models/) - identity, access, and application models.
- [`02-skeleton-loading`](02-skeleton-loading/) - loading and skeleton behavior.
- [`03-data-grid-platform`](03-data-grid-platform/) - data grid and collection platform.
- [`04-application-shell-design`](04-application-shell-design/) - application shell and navigation.
- [`05-enterprise`](05-enterprise/) - enterprise readiness.

Use this parent folder for family-level navigation, then load only the child packs required by the requested outcome.
