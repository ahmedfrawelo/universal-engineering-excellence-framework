# Frontend Design Production Gate

Pass only when every selected item has current evidence:

- architecture and design-system ownership were inspected before implementation;
- material design work has a valid `DESIGN.md` contract;
- the route selected one primary director and only applicable specialists;
- Taste was not selected for dashboards, admin, data grids, or dense product UI;
- when Taste was selected, route evidence contains both `taste-preflight` and `taste-final-check`;
- both Taste phases prove no duplicate CTA intent, no repeated section-layout family, no third consecutive zigzag split, and acceptable eyebrow density;
- a selected Styleseed review scored at least 80 and the final render was reverified;
- Penpot live use, when claimed, proves configuration, reachability, plugin connection, target file, and a successful task-relevant operation;
- exact behavior, accessibility, responsiveness, theme/RTL states, tests, and applicable UEEF gates pass.
- a current frontend execution artifact validates with `scripts/validate-frontend-execution-evidence.mjs` and contains every phase selected by the deterministic route;
- after frontend mutation, the final `UIUX:` label is substantive and is not `NA`.

Any missing item is `ACTIVE`, not `COMPLETE`.
