# Server Side

Server Side is a parent family for related UEEF framework packs.

## Child packs

- [`01-api`](01-api/) - API contracts and transport rules.
- [`02-backend`](02-backend/) - backend application and service engineering.
- [`03-database`](03-database/) - persistence, schema, query, and migration engineering.

Use this parent folder for family-level navigation, then load only the child packs required by the requested outcome.
