# Framework Resources

Framework Resources is a parent family for related UEEF framework packs.

## Child packs

- [`01-templates`](01-templates/) - reusable templates.
- [`02-examples`](02-examples/) - examples.
- [`03-scripts`](03-scripts/) - script guidance.
- [`04-reference`](04-reference/) - reference material.
- [`05-roadmap`](05-roadmap/) - roadmap.
- [`06-changelog`](06-changelog/) - changelog.
- [`07-future`](07-future/) - future direction.

Use this parent folder for family-level navigation, then load only the child packs required by the requested outcome.
