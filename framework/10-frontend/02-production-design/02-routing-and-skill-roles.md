# Routing and Skill Roles

| Surface or intent | Primary director | Conditional supplement |
| --- | --- | --- |
| Dashboard, admin, settings, data grid, dense product UI | `interface-design` | domain skills only |
| Landing page, portfolio, marketing, expressive redesign | `frontend-design` | `design-taste-frontend` |
| Material design review or scoring | existing director | `styleseed-design-review` |
| Explicit Figma artifact | task-appropriate director | Figma plugin |
| New Penpot/canvas work | task-appropriate director | Penpot MCP after live health proof |

Taste supplies visual judgment and its variance, motion, and density dials. When selected, it is not a loose suggestion: `taste-preflight` runs before implementation and `taste-final-check` runs before review or delivery. Both phases must check duplicate CTA intent, repeated section-layout families, excessive zigzag alternation, and eyebrow density. It is not the authority for dashboards or data-heavy product UI. Styleseed is a reviewer/gate, not a replacement implementation director.
