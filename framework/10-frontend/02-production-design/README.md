# Frontend Design Production

This pack turns design intent into a governed, testable production route. It keeps durable design truth in `DESIGN.md`, selects one primary design director, uses Taste only for expressive surfaces, applies Styleseed as a measured post-build loop, and prefers Penpot for new UEEF-controlled canvas work.

It does not make an external tool healthy by declaration. Penpot is live only after configuration, reachability, plugin connection, and target-file evidence pass.
