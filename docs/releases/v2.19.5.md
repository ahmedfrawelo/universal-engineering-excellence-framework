# UEEF 2.19.5

Release date: 2026-07-31

## Summary

This patch keeps Codex runtime recovery data outside `CODEX_HOME` so synchronization providers cannot create backup conflicts alongside live Codex state.

## Changed

- Windows Codex backups default to `%LOCALAPPDATA%\Codex-Recovery\UEEF-backups` for the active `CODEX_HOME`.
- `scripts/install-codex.ps1` and `scripts/sync-runtime.ps1` accept `-BackupRoot`.
- `UEEF_BACKUP_ROOT` provides the equivalent environment override.
- Custom or test Codex homes default to an external sibling recovery directory.
- Backup roots inside `CODEX_HOME` are rejected.
- Existing reparse-point backup roots are rejected.
- Managed `AGENTS.md` rollback copies use the same external backup policy.

## Verification

- Installer tests prove external backup creation, internal-path rejection, and no recreation of `CODEX_HOME/ueef/backups`.
- Framework validation, release consistency, runtime synchronization, runtime drift, and continuous assurance pass.
