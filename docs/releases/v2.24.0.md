# UEEF 2.24.0

Release date: 2026-08-02

## Summary

This release makes active-goal convergence and user-owned Chrome task isolation executable, fail-closed, and cross-platform verified.

## Added

- Added schema-version-2 Completion Audits with verbatim goal coverage, acceptance evidence, actual implementation inventory, reverse traceability, changed-surface regression review, and explicit user-commitment/update accounting.
- Added five deterministic routes for goal updates: current step, prior-step correction, future step, current-work invalidation, and conflict or ambiguity.
- Added a dedicated task-tab contract that preserves the user's working tab while remaining inside the same existing Chrome window, profile, and signed-in session.
- Added guarded emergency loopback readiness requiring explicit user authorization, complete prior-stage failure evidence, exact target identity, and loopback-only browser and target WebSockets.
- Added local-service readiness that reuses a listener only after both health and project ownership are proven.

## Hardened

- Prevented `COMPLETE` when implementation is missing, untraced, unsupported by current evidence, or affected by a pending goal update, resume point, or before-finish commitment.
- Required separate current-step and conservative overall progress percentages with named phase, evidence, current action, and next gate.
- Prevented post-completion follow-up questions from reopening a proven bounded goal.
- Rejected unknown Unix lifecycle states/phases and case-variant secret markers in browser failure reports.
- Aligned Node completion validation with PowerShell timestamp, future-evidence, and duplicate-ID checks.
- Kept generated Codex `AGENTS.md` below its precedence-only size budget and kept PowerShell test sources safe for Windows PowerShell 5.1.

## Verification

- Focused completion-audit, goal-lifecycle, browser-control, local-service, remote-debugging, preflight, syntax, and enforcement suites pass on the source checkout.
- PowerShell and Unix lifecycle paths reject the new negative fixtures.
- Full framework assurance, installed runtime drift/source revision, exact-commit GitHub Actions, push, tag, and published GitHub Release remain mandatory release gates.
