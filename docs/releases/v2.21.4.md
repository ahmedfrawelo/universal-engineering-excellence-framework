# UEEF 2.21.4

Release date: 2026-07-31

## Summary

This patch restores trustworthy cross-platform releases and removes proven validation waste without weakening the full release gate.

## Fixed

- Updated the stale Unix dashboard routing assertion to require `interface-design`, matching the canonical product-interface route and Windows tests.
- Prevented GitHub release publication until the `Validate UEEF` workflow succeeds for the exact commit being released.
- Removed the stale machine-specific `E:` Codex-home fallback; explicit configuration and `CODEX_HOME` remain authoritative.
- Added deterministic accessibility, security, and performance checklist overlays for three pinned preferred skills whose upstream packages referenced missing files.
- Suppressed repeated nested validator output from the PowerShell assurance JSON path.

## Performance

- Added `--skip-nested-tests` to Unix structural validation and used it for installer source/stage checks.
- Made Unix quick assurance use structural validation after the workflow's full validation step.
- Reduced a measured Unix validator pass from 41,163 ms to 9,575 ms and the repeated assurance path from 48,449 ms to 21,018 ms in the recorded Git Bash benchmark.

## Verification

- Windows nested framework validation passes.
- Unix full and structural validation pass.
- Installer integration, preferred-skill integrity, release consistency, and assurance checks pass.
