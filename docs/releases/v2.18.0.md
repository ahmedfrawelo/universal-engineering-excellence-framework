# UEEF 2.18.0

Release date: 2026-07-24

- Added a per-user Windows scheduled task for Codex that checks `origin/main` every 15 minutes.
- When a newer commit exists, the task updates the source checkout and synchronizes the runtime without overwriting local source changes.
- The update launcher uses `wscript.exe`, so no terminal panel is shown to the user.
- Update activity is recorded under `CODEX_HOME/ueef/logs/auto-update.log`.
