# UEEF 2.22.0

Release date: 2026-08-01

## Summary

This release makes preferred capability management complete and truthful across user-installed skills, Codex plugins, and runtime-managed MCPs.

## Added

- Added `config/preferred-capabilities.json` as the unified preference contract for 27 user skills, 15 Codex plugins, and the Node REPL MCP.
- Added `scripts/reconcile-preferred-capabilities.ps1` with a missing-only `-Install` mode.
- Added explicit installer options for Windows and Unix Codex installations.
- Added regression coverage for complete declarations, remote plugin registration, missing platform actions, and installer wiring.

## Behavior

- Missing user skills are installed from their pinned sources when installation is explicitly requested.
- Bundled plugins and MCPs remain owned by the Codex runtime.
- Remote plugins remain platform-managed and produce an actionable report instead of being copied or downloaded as fake user skills.
- Capability health now reports missing preferred plugins and MCPs even when no cache or configuration evidence exists.

## Verification

- Preferred capability reconciliation reports 43 total capabilities and zero missing items on the reference Codex installation.
- Framework validation, cross-platform script syntax, environment bootstrap, and capability-health tests pass.
- Codex, Cursor, generic, Windows, Unix, rollback, and staging installer tests pass.
- Full assurance passes within the configured performance budget.
