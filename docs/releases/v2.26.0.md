# UEEF 2.26.0

Release date: 2026-08-08

## Highlights

- Added a provenance-tracked, unmodified GitHub Spec Kit `v0.16.1` source snapshot at commit `ad4104b56c219b0a27bac06547d1a3c7d6a0dbd6`, including the upstream MIT license and a mechanically verified aggregate digest.
- Added an independently owned UEEF task-graph engine with dependency-cycle detection, critical-path ordering, literal write ownership, risk isolation, bounded token and worker budgets, and dynamic grow/shrink team recommendations.
- Added atomic, graph-bound execution state with `PENDING`, `READY`, `RESERVED`, `RUNNING`, `BLOCKED`, `DONE`, and `FAILED` transitions, bounded retries, dispatch release, evidence-backed completion, resume, and concurrent revision protection.
- Added Codex, Claude, and generic host dispatch contracts without hidden worker creation or implicit upstream command execution.
- Extended `.ueef/specs/<id>` to generate and validate `task-graph.json` alongside the existing specification, plan, task, evidence, clarification, and convergence artifacts.

## Security boundary

- The UEEF CLI validates upstream workflows but exposes no upstream run command.
- Shell-step definitions are denied by default, and shell execution remains disabled even when a definition is accepted for analysis.
- Community workflows, custom steps, extensions, presets, and bundles are not imported or activated automatically.
- Graph, state, task count, ownership paths, evidence, error, and worker inputs are bounded and validated.

## Verification

- 33 focused Python tests cover graph validation, cycles, critical paths, path conflicts, budgets, retries, resume, reservation, release, worker ownership, graph drift, and a real two-process scheduling race.
- PowerShell integration tests cover generation, upstream digest verification, state initialization, Codex dispatch contracts, release and replacement dispatch, start, evidence-backed completion, token accounting, and final team shrink.
- Ruff, Pyright, and Bandit pass for UEEF-owned engine code.
- The official bundled `speckit` workflow validates successfully through the vendored upstream engine with its locked optional dependencies.
- Full UEEF framework validation and release consistency pass with the complete payload.
