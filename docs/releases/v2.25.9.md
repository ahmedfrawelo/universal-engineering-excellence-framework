# UEEF 2.25.9

Release date: 2026-08-05

## Summary

Patch release for reducing token-heavy repository discovery and nested validation noise during runtime hardening and sync workflows.

- Added generated `framework/_domains/` navigation so agents route by domain before scanning the stable numbered pack inventory.
- Excluded embedded repository-intelligence internals from project context-map discovery while still reporting generated/output candidates.
- Added regression coverage for embedded-engine pruning in PowerShell and shell context-map tests.
- Added quiet-mode support for nested runtime sync, active-state, framework validation, and fresh-review evidence validation calls.
- Documented the public runtime sync boundary change in ADR-009.
