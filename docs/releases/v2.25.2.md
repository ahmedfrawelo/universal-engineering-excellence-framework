# UEEF 2.25.2

Release date: 2026-08-04

## Summary

This patch release republishes the completed 2.25.x runtime-enforcement payload with a CI fix for the offline repository graph viewer asset. The previous `v2.25.1` tag reached GitHub before release publication, but its Windows validation failed because the pinned `vis-network.min.js` asset was still eligible for text normalization.

## Fixed

- Marked `vendor/repository-intelligence-engine/graphify/assets/vis-network-9.1.6/vis-network.min.js` as `-text` in `.gitattributes` so Git checkout cannot rewrite line endings and invalidate the pinned SHA384/SRI check.
- Kept the offline viewer asset hash stable across Windows and Unix validation.

## Included from 2.25.1

- Executable model routing and Codex App Server dispatch helpers.
- Frontend design production governance and evidence validators.
- Fresh-context review protocol, templates, and tests.
- Browser-control recovery hardening.
- Repository graph viewer validation and offline assets.
- Optional capability-health handling that reports warnings without degrading overall health when no blocking diagnostics exist.
