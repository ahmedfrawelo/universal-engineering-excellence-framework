# UEEF 2.21.2

Release date: 2026-07-31

## Summary

This patch fixes unreadable Arabic/English route-status messages. The old template placed the intent, tier, agent decision, and browser decision in one inline-code line separated by pipes, which caused bidirectional reordering and awkward wrapping in Codex.

## Changed

- Route rationale now uses a localized four-item list with one field per line.
- Arabic responses use the labels `المطلوب`, `المستوى`, `الوكلاء`, and `المتصفح`.
- Other response languages translate the same four labels instead of inheriting an English-only status line.
- Ordinary mixed Arabic/English prose now relies on the Codex renderer.
- Inline code is reserved for genuine identifiers and commands, not complete sentences or status blocks.

## Safety

- Hidden bidirectional control characters remain prohibited in code, commands, paths, configuration, JSON/YAML, and saved artifacts.
- Machine-readable route objects and final UEEF verification labels are unchanged.

## Verification

- Intent-fidelity tests reject the obsolete pipe-separated route template.
- Framework validation confirms the source loader, core policy, final-response policy, and generated runtime use the new format.
- Full Windows framework validation passes.
