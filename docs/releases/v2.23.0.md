# UEEF 2.23.0

Release date: 2026-08-01

## Summary

This release converts critical UEEF rules from instruction-only guidance into executable, evidence-backed completion gates.

## Added

- Configurable architecture ownership and dependency policy with automated forbidden-dependency and ADR checks.
- Automated file-organization reporting for unowned root source files, generic dump folders, owner mapping, and oversized-file review.
- One enforcement registry mapping all 32 selectable quality gates to 19 evidence domains.
- A task-evidence generator that creates every selected domain and automatically pairs Architecture with file organization.

## Hardened

- Long active goals require both a conservative progress percentage and explicit phase.
- Performance evidence requires measured baseline, remeasurement, and budget values with units.
- Security, testing, accessibility, UI/UX, and code-quality domains require appropriate evidence kinds.
- Commands require a zero exit code and observation time; reviews require an identified reviewer; file evidence requires an existing file and matching SHA-256.
- Validation rejects omitted selected gates, unknown domains, placeholders, pending records, and non-passing automated reports.
- Quality-gate path parsing is separator-neutral on Windows and Unix, and the generated AGENTS policy remains within its precedence-only size budget.

## Verification

- Architecture, file-organization, evidence-generation, enforcement-coverage, semantic-evidence, goal-lifecycle, and cross-platform syntax tests pass.
- Full source validation and nested deterministic tests pass.
- Codex, Cursor, generic, rollback, and staged-runtime installer tests pass with the complete tracked payload.
- Runtime drift, CI, push, and published-release verification remain release gates until the exact commit is installed and published.
