# UEEF 2.21.5

Release date: 2026-08-01

## Summary

This patch prevents Arabic task requests from bypassing proportional routing and makes two previously silent Codex readiness failures visible.

## Fixed

- Added a Windows PowerShell 5.1-safe Arabic signal normalizer for common explanation, change, audit, broad-scope, UI, browser, current-documentation, debugging, security, and release language.
- Reused those signals in task classification, capability selection, and quality-gate selection.
- Added equivalent Arabic frontend signals to the canonical Node route engine without over-selecting unrelated table, theme, or design-system routes.
- Added plugin capability diagnostics for more than three default prompts, prompts longer than 128 characters, and skill icon paths that escape the owning skill directory.
- Added a GitHub release-credential readiness check that accepts authenticated `gh`, environment tokens, or a non-interactive Git Credential Manager credential while discarding secret material after the check.

## Performance

- Representative warmed Arabic preflight runs completed in 139-240 ms; the first broad audit route completed in 953 ms.
- Final full assurance completed in 147,133 ms against the 360,000 ms budget.

## Verification

- Arabic broad repair, focused frontend repair, and read-only explanation regression cases pass.
- Capability-health, environment-bootstrap, frontend-routing, quality-gate, and cross-platform syntax tests pass.
