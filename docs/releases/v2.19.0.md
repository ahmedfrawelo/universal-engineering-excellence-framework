# UEEF 2.19.0

Release date: 2026-07-29

## Fixed

- Task text is no longer discarded when a caller omits route numbers, tags, risk floors, or code-change signals.
- Preflight no longer reports an ambiguous `READY` as proof that an installed runtime is active.
- Relative repository paths now work for status and health diagnostics.
- Source checkouts no longer claim false `AGENTS.md` or active-state passes.
- Unix status and preflight now distinguish validated source checkouts from active managed runtimes and block execution when neither state is valid.
- Diff-impact analysis now trusts the explicitly selected repository safely, suppresses line-ending noise, and fails instead of returning a false empty result when Git cannot inspect it.
- Quality-gate selection no longer preloads broad Guardian and environment modules for every low-risk task.
- Removed repeated generic contracts from 166 module, decision-graph, gate, scorecard, and template files; each now carries concern-specific decisions and evidence.

## Added

- Shared `scripts/get-ueef-task-classification.ps1` contract with explicit/inferred/mixed evidence.
- Behavioral classification fixtures covering read-only, UI, browser, backend, and critical migration tasks.
- Tier-aware quality selection JSON output and T0/T1/T2+ policy tests.
- Architecture documentation for source/runtime layers, activation, state, drift, selectors, and cross-platform boundaries.
- Replaced generic security-pack boilerplate in the selected authentication, authorization, input-validation, OWASP, database, and security-default modules with threat-boundary rules and direct verification criteria.
- Cross-platform source-status and module-specificity regression tests wired into both framework validators.
- Installer guidance now matches the capability registry: UI/UX specialist skills are preferred profile capabilities with explicit fallbacks, not global mandatory dependencies.
- Added a pinned preferred-skills manifest and cross-platform missing-only installer covering the complete supported design, motion, and Hatch Pet set.
- Classified legacy `codex-primary-runtime` as a runtime component and retired the unprovenanced `codex-home-recovery` folder in favor of transactional rollback and backups.
