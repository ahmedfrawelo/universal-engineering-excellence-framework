# UEEF 2.25.11

Release date: 2026-08-06

## Summary

Patch release that finalizes token-aware routed execution and closes delivery-quality gaps in embedded-engine CI coverage, Arabic intent routing, explicit task authorization, and framework text encoding.

## Changed

- Finalized catalog-backed model routing, bounded token-economy execution specs, direct App Server dispatch receipts, and managed enforcement introduced after `v2.25.10`.
- Added a dedicated CI job that installs the embedded repository engine from its lockfile and runs all pytest tests plus the governed Ruff rule set.
- Restored real UTF-8 Arabic signals for landing pages, visual design review, and Penpot/design-canvas requests.
- Removed the Arabic `جيد` false-positive from explicit new-task authorization while retaining correct `جديد`, `جديدة`, and `جديده` forms.
- Corrected remaining mojibake punctuation in the fresh-review and long-term-maintenance modules and added a Markdown validation guard.
