# UEEF 2.20.0

Release date: 2026-07-31

## Summary

This minor release makes frontend governance proportional. Small existing-owner fixes stay focused, new production surfaces receive the full construction baseline, and audits receive deep design evidence without turning every frontend task into a complete redesign workflow.

## Changed

- Added machine-readable `Quick`, `Build`, and `Audit` frontend modes.
- Added a canonical frontend-mode contract under Pack 10.
- Replaced the universal `ui-ux-pro-max` plus `impeccable` pair with independent skill triggers.
- Routed `typeui-fundamentals` to lightweight principles, `frontend-design` to production construction, `impeccable` to critique and polish, and `ui-ux-pro-max` to explicit product or style intelligence.
- Limited skeleton selection to skeleton, loading-placeholder, async-state, reveal-timing, or paired-structure changes.
- Limited visual-composition gates to material build/audit scope or explicit visual acceptance criteria.
- Updated capability profiles, environment bootstrap, activation gates, runtime generation, and Unix preflight to use the same proportional contract.

## Compatibility

- Existing task descriptions remain supported; frontend mode is inferred automatically.
- Callers can explicitly override automatic frontend mode selection in the PowerShell quality-gate selector.
- Missing optional design skills no longer block unrelated frontend work.

## Verification

- Windows and Unix framework validation pass.
- Quality-gate selection tests cover all three frontend modes and explicit override behavior.
- Capability-profile and task-preflight tests prove minimal skill chains on Windows and Unix.
- Skeleton contract tests prove that data-backed UI alone does not trigger the skeleton workflow.
- Managed runtime synchronization and source/runtime drift checks pass.
