# UEEF 2.21.1

Release date: 2026-07-31

## Summary

This patch makes the canonical task-routing pipeline materially faster without removing validation or weakening skill selection. Classification now computes frontend route evidence once, and downstream capability-profile, quality-gate, and preflight stages reuse the same validated object.

## Performance

- Quality-gate selection median: 162.5 ms to 63.9 ms, 60.7% lower.
- Task preflight median without a health probe: 228.3 ms to 155.7 ms, 31.8% lower.
- Direct route, classification, capability-profile, and status controls remained within normal process-start variance.
- Direct non-frontend capability profiles retain a no-Node fast path; measured medians were 1.7 ms for a core explanation and 2.1 ms for a backend implementation classification.

Measurements used one warm PowerShell process, one warm-up, and seven samples per case. Correctness tests ran before the final measurement.

## Changed

- Exposed canonical frontend-route evidence from task classification.
- Added validated route-object reuse to capability-profile and quality-gate selectors.
- Added an explicit frontend-force signal for callers with an authoritative `ui` task tag.
- Added explicit mutation override support while retaining route-text inference for ordinary callers.

## Fixed

- Removed the second Node route-engine process from UI quality-gate and preflight paths.
- Prevented noun-only frontend explanations from inventing implementation work.
- Rejected stale or cross-task supplied route objects.
- Prevented the optimization from slowing direct core and backend profile selection.

## Regression protection

- Preflight tests use a counting pass-through Node shim and require exactly one real route-engine invocation.
- Capability-profile tests prove core and backend paths work with no Node executable available.
- Routing tests cover read-only explanations, explicit UI tags, mutation fidelity, and cross-task route rejection.

## Verification

- Full Windows framework validation passes.
- Capability profile, task classification, frontend routing, preflight, quality-gate, release-consistency, and runtime contracts pass.
- The measured performance gains retain identical selected skills, modules, gates, and route evidence for covered tasks.
