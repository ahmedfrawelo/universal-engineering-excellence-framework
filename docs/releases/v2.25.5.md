# UEEF 2.25.5

Release date: 2026-08-04

## Summary

This patch release supersedes `v2.25.4` after GitHub Actions exposed Unix preflight trying to discover a live Codex App Server during CI and installer validation. Unix preflight now reports model availability as unavailable instead of attempting a host-specific live catalog.

## Fixed

- Updated `scripts/get-ueef-task-preflight.sh` to pass `--models-unavailable` to Unix route selection, preventing `spawn codex ENOENT` failures in CI and generic installer validation.
- Preserved the existing Unix limitation that capability health and callable probes are unsupported.

## Verification

- Full framework validation must pass on GitHub Actions before publishing the GitHub Release object.
